    指南
    
          
    怎么用本控制台
    
          
    留在应用内学习：实验、单机、多机与本指南。不必再打开外部文档。
    
        
    
        
    
          
    
            
    本页目录
    
            1. 先认识界面
            2. 背景 / 亮暗 / 语言
            3. 单机怎么飞
            4. 多机怎么跑
            5. 地图与俯视
            6. 验收实验
            7. 常见问题
          
    
          
    
            
    
              
    1. 先认识界面
    
              
    左侧是任务导航：实验、单机、多机、指南。点哪一页，中间就切换到对应任务，不用离开本窗口。
    
              
      
                
    • 实验：跑六项验收，看结果与日志（默认首页）。
      • 
                
    • 单机：选规划器、选地图、设目标，再启动仿真。
      • 
                
    • 多机：选协同模式、机数 / 队形、地图，再启动。
      • 
                
    • 指南：本页说明，随时查阅怎么用控制台。
      • 
              
    
            
    
            
    
              
    2. 背景 / 亮暗 / 语言
    
              
    顶栏右侧可随时改外观，不影响仿真配置：
    
              
      
                
    • 背景：点预设缩略图，或上传本地图片。
      • 
                
    • 日间 / 夜间：日间为 CSS 毛玻璃，夜间启用液态玻璃。
      • 
                
    • EN / 中文：切换界面语言，选择会记住。
      • 
              
    
            
    
            
    
              
    3. 单机怎么飞
    
              
      
                
    1. 打开单机页。
      2. 
                
    2. 在「规划器」大卡片里点选一条路径（A–H）。
      3. 
                
    3. 在「地图」卡片里选场景（也可改种子 / 最大速度）。
      4. 
                
    4. 右侧点启动。需要看 3D 时勾选 RViz。
      5. 
                
    5. 在 RViz 用 2D Goal Pose 发目标；俯视面板会显示障碍与轨迹。
      6. 
                
    6. 结束用停止；要重来点重启。
      7. 
              
    
              
    提示：单机页顶部的预设（如 Dyn-A*、走廊）会自动选好规划器 + 地图。
    
            
    
            
    
              
    4. 多机怎么跑
    
              
      
                
    1. 打开多机页。
      2. 
                
    2. 选任务：EGO-Swarm / 共享空域避障 / 编队。
      3. 
                
    3. 设机数与队形（若该模式需要）。
      4. 
                
    4. 选地图后点启动。
      5. 
              
    
            
    
            
    
              
    5. 地图与俯视
    
              
    单机 / 多机页右侧是「地图 · 俯视」：障碍、实际轨迹与规划轨迹叠在一起。可切换「机头朝上 / 北朝上」，拖底边改高度。
    
              
    下方监控区显示位置、速度、告警、FSM 与日志。仿真控制条位于监控区上方：停止 / 重启 / 启动。
    
            
    
            
    
              
    6. 验收实验
    
              
      
                
    1. 打开实验页。
      2. 
                
    2. 需要观看时勾选「验收时打开 RViz2」。
      3. 
                
    3. 点击运行全部 6 项，或在列表里单项「运行」。
      4. 
                
    4. 右侧看结果历史；报告目录显示在页内。
      5. 
              
    
            
    
            
    
              
    7. 常见问题
    
              
      
                
    • 点启动没反应：看进程日志；确认本机 ROS / 工作空间已按 README 装好。
      • 
                
    • 俯视空白：先启动仿真，等地图点云上来；状态会提示「等待地图」。
      • 
                
    • 背景换不了：硬刷新一次；大图上传后稍等加载。
      • 
                
    • 只想看界面、不飞：仍可浏览各页与预设；启动才会拉起仿真进程。
      • 
              
    
              
    本指南就在控制台里。侧栏点「指南」随时回来，不必另开浏览器页。
